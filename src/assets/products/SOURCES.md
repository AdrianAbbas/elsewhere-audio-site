# Product image sources

Product art copied from the developer's own plugin repositories (read-only, `git show HEAD:<path>`). All of it is original: Blender renders and interface captures made by those repositories' scripts (see each repo's `docs/ART_SOURCES.md`). The painted DUNGEON CRAWLER and LIGHT SEEKER scenes are cropped above the plugin's control strip. Pixel screenshots live in `public/images/worldbuilder/` as lossless PNG.
